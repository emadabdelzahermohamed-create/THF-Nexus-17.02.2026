# Top Hero Fit: no-upfront funding route — 24 October 2026

## Decision and evidence
Use project sponsorship as a separate route from THF token sales. Do not spend money on listing, ads, liquidity or transaction gas. No received money, approved sponsorship account or sponsor commitment is claimed.

Closest verified example: wger is a free fitness/workout/nutrition application with a web and mobile client and an active GitHub Sponsors profile: https://github.com/sponsors/wger-project . This proves use of the route, not that wger began with literally zero resources or that THF will receive the same outcome.

Buffer tested interest using a minimal page and pricing before expanding its working product: https://buffer.com/resources/idea-to-paying-customers-in-7-weeks-how-we-did-it/ . Reuse demand validation; do not promise an unfinished product or imply a same-day result.

GitHub supports sponsorship recipients in Egypt and charges no GitHub fee on personal-account sponsorships; organization sponsorships can incur fees. Official source: https://docs.github.com/en/sponsors/getting-started-with-github-sponsors/about-github-sponsors . Eligibility is for open-source contributors. Public repository visibility alone does not establish an open-source license: confirm the contribution/license scope before submitting.

Enrollment requires bank/tax information, 2FA and approval: https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account . This cannot be represented as anonymous enrollment or instant payout. Owner financial/identity information must stay outside Git and chat.

## Activation checklist
1. Sign in to the existing GitHub account at https://github.com/sponsors/accounts (the browser reached the sign-in page on 24 October).
2. Confirm eligible open-source contribution scope and account identity. Existing GitHub owner is a personal account; project copy uses Top Hero Fit and project contact TopHeroFit@gmail.com. Do not present the personal account as an incorporated organization.
3. Enter owner bank/tax information privately and complete any required owner verification/terms. Do not invent a fiscal host, company, region or bank details.
4. Submit profile for approval; retain actual confirmation if provided.
5. Only after approval, publish tiers and add a verified functioning Sponsor link. Do not add an inactive FUNDING.yml or pretend checkout is available.
6. Measure approved profile, actual sponsors, gross receipts, fees and funds available separately. Current verified receipts remain zero.
