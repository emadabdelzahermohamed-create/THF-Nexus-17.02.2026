## Selection ruling

For THF's current stage, the correct capital stack is:

**Strategic/private capital → UAE issuer/regulatory package → curated launch partner → Solana-native TGE → disclosed DEX liquidity → professional liquidity provisioning.**

Do not invert this order by opening a thin mainnet pool first. A low-liquidity token before the product/community/issuer package is ready creates fragile price action and makes serious launch partners harder to secure.

## Current launch hypothesis

- Strategic/private partner: Republic / Impossible / Animoca.
- Curated public distribution: MocaList/CoinList as first-choice fit because THF spans gaming, consumer product and culture; Legion as a parallel candidate after the legal package is ready.
- On-chain TGE: Metaplex Genesis on Solana. Use Launch Pool for broad organic price discovery; use fixed Presale only if a reviewed price/valuation exists; use Uniform Price Auction when bid-based discovery better fits investor composition.
- Market creation: route a disclosed fraction of launch proceeds and token treasury allocation into Raydium and/or Meteora rather than manufacturing volume.
- Liquidity management: use treasury multisig and a written professional liquidity mandate; never personal wallets or undisclosed self-trading.

## Acceptance criteria before public launch

1. Working UAE issuer/legal structure and exact token classification.
2. Whitepaper/disclosures and participant-jurisdiction process accepted by launch/distribution partner.
3. Token utility model backed by real product flows, not speculative labels.
4. Supply/allocation/vesting/treasury model with no hidden allocations.
5. Proof-of-Workout Devnet evidence and production-app traction evidence.
6. Multisig treasury and incident/authority controls.
7. Independent smart-contract/token configuration review where required.
8. Written liquidity plan defining paired capital, venue, lock/vesting, custody and market-making limits.
